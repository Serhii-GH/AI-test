# Архітектура Telegram-бота

Це простий Telegram-бот на Python та бібліотеці **aiogram**. Він працює у режимі polling: програма регулярно запитує Telegram, чи надійшли нові повідомлення.

## Frontend

Frontend — це частина, яку бачить користувач. У нашому застосунку окремого сайту або мобільного інтерфейсу немає: frontend уже надає застосунок **Telegram**. Користувач вводить команди в чаті з ботом і бачить його відповіді там само.

## Backend

Backend — це код, який обробляє команди та готує відповіді. У проєкті він міститься у файлі `app/main.py`.

Там створюються бот і `Dispatcher` aiogram, а також описані обробники команд `/start` і `/help`. Токен бота завантажується зі змінної `BOT_TOKEN` у файлі `.env`.

## Database

Бази даних у поточній версії **ще немає**. Бот не зберігає користувачів, повідомлення чи інші дані: він просто одразу відповідає на отриману команду.

У майбутньому база даних знадобиться, наприклад, для профілів користувачів, історії запитів або налаштувань бота.

## API

API — це спосіб, яким програми обмінюються даними. Наш бот використовує **Telegram Bot API** через бібліотеку aiogram: отримує з Telegram повідомлення користувача та надсилає через нього відповіді.

Власного API (наприклад, окремого HTTP-сервера для інших застосунків) у проєкті **ще немає**.

## Як працює команда `/start`

1. Користувач надсилає в чаті команду `/start`.
2. Telegram передає це оновлення боту через Telegram Bot API.
3. Aiogram отримує оновлення, а `Dispatcher` визначає, що для `/start` треба викликати `start_handler`.
4. `start_handler` записує подію в лог і формує привітальне повідомлення зі списком команд.
5. Метод `message.answer(...)` надсилає відповідь назад через Telegram Bot API.
6. Telegram показує відповідь користувачеві в чаті — це і є наш frontend.
